# Apresentação do TCC — pitch de 3 minutos (11/11)

| Arquivo | O que é |
|---|---|
| `FashionAI_pitch.pptx` | 7 slides (16:9) com notas do apresentador — importe no Google Slides |
| `FashionAI_video_pitch.mp4` | Vídeo de 57 s, 1920×1080, **sem narração** (trilha de áudio muda) para você gravar a sua voz por cima |

As telas são capturas reais do sistema rodando localmente (API Spring Boot + frontend Next.js + MySQL local), com uma
conta de demonstração fictícia (`ana.demo`) e peças cadastradas a partir das imagens de `media/assets_pecas`. Nenhum
dado de produção nem IA paga foi usado: a análise das peças usou o motor local.

## Como montar no Google Slides

1. Envie os dois arquivos para o seu Google Drive.
2. Abra o `.pptx` com **Abrir com → Apresentações Google** (ou em um Slides em branco: **Arquivo → Importar slides**).
   As fontes são Fraunces e Inter, que o Google Slides já tem.
3. Grave a narração sobre o vídeo (roteiro abaixo), exporte o MP4 final e envie esse arquivo também para o Drive.
4. No slide 4 (o do botão de play): **Inserir → Vídeo → Google Drive**, escolha o vídeo narrado, estique-o para
   cobrir o slide inteiro e apague a imagem de fundo.
5. Com o vídeo selecionado: **Opções de formato → Reprodução de vídeo → Reproduzir (automaticamente)**.
   Teste em **Apresentar** para conferir que ele começa sozinho.
6. Troque `[nome da equipe]` no slide 1 e coloque a apresentação na pasta da professora até **terça, 10/11**.
