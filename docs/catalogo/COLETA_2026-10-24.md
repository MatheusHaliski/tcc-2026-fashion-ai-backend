## Amostra do Total frame nas fotos do acervo novo (plano de enquadramento)

`process_local_sd.py --no-ai --dry-run` (modo arquivo, sem banco) em 236 fotos de 32 marcas (8 por marca; 103
superiores, 50 inferiores, 35 calçados, 40 acessórios, 8 peças inteiras): isolar a peça, centralizar com a maior aresta em
50 % do quadro 3:4, fundo branco, altura < 25 % da foto → inelegível.

| Estado | Fotos | Observação |
| --- | --- | --- |
| RENDERED | 114 | packshot gerado |
| RETRY | 98 | HTTP_429 (98) |
| REVIEW | 12 | EXCESSIVE_MASK_REMOVAL (5); TARGET_MASK_EMPTY (4); TARGET_MASK_EMPTY_AFTER_CLEANUP (3) |
| INELIGIBLE | 7 | SOURCE_GARMENT_BELOW_MIN_HEIGHT (7) |
| REJECTED | 5 | BELOW_MINIMUM_300X300 (5) |

Os 100 `RETRY` são HTTP 429 dos CDNs VTEX quando o lote baixou em rajada; a polidez por host (`--min-interval`, commit
`5c7e0704`) resolve e o reprocessamento dessas fotos fica para a execução de produção. Altura da peça na foto
(n = 121): mediana 0.55; **7 inelegíveis** (< 25 %), listadas em `ineligible.json` para a quarentena
auditada (`quarantine_unsafe_products.py`) — nenhum produto é apagado pelo lote. Fotos de produto (tênis, jeans) saem
como packshot limpo; em foto com modelo o segmentador de roupa pode manter um antebraço — com o parser humano local
(`CATALOG_PHOTO_PARSER_WEIGHTS`, ver `scripts/catalog/README.md`) a mesma camiseta Converse saiu sem o braço (46 de 48
fotos do subconjunto com modelo renderizadas). As imagens da amostra ficaram fora do repositório (fotos oficiais das
marcas, só referência).

## Como publicar (quem roda é o responsável, com as credenciais de produção)

```bash
# 1. importar o acervo novo (só insere o que não existe; o acervo anterior continua intacto)
scripts/catalog/import_railway.sh <host> <porta> --dry-run      # ensaio
scripts/catalog/import_railway.sh <host> <porta>                 # importa todos os data/catalog/acervo/*.jsonl.gz com --skip-existing

# 2. Total frame das fotos novas no catálogo (whole_url / photoSet, que a interface já exibe)
pip install -r scripts/catalog/requirements-whole.txt
CATALOG_PHOTO_PARSER_WEIGHTS=/caminho/para/parser python scripts/catalog/process_photo_sets.py --limit 500 --dry-run
CATALOG_PHOTO_PARSER_WEIGHTS=/caminho/para/parser python scripts/catalog/process_photo_sets.py --apply --limit 8000

# 3. quarentena das peças com altura < 25 % (relatório antes, aplicação só depois de ler)
python3 -m scripts.catalog.quarantine_unsafe_products --report work/catalog-quarantine.json
```

O `import_railway.sh` lê todos os `data/catalog/acervo/*.jsonl.gz`, então o complemento abaixo entra no mesmo passo 1.
