# Composições visuais AURA e cards com score

Esta é a seleção principal solicitada: arquivos de imagem e GIFs, sem depender de exemplos genéricos de desfiles.

![Prancha de referências](prancha-composicoes.jpg)

[Painel com reprodução de GIFs](index.html) · [Dados verificados](media.json) · [Resumo da execução](summary.json)

Python buscou os arquivos indicados por uma busca visual na web e verificou seu formato, dimensões e quadros. Foram validadas 24 mídias, incluindo 3 GIFs animados. Duas mídias ultrapassaram o limite de download, uma falhou e um serviço de boost foi excluído. Prévias de vídeo não foram contadas como GIFs.

Os arquivos originais foram guardados apenas na pasta de trabalho; as miniaturas são referências com links para suas fontes. Licenças para incorporar materiais de terceiros ao app não foram verificadas. O visual implementado do FashionAI deve ser original.

## Reproduzir

```bash
python3 scripts/design/collect_aura_compositions.py
```

Requer Pillow. A lista de URLs vem de `docs/design/referencias-aura/compositions-sources.json`, descoberta por busca de imagens e revisada para relevância. Os downloads originais ficam em `work/aura-compositions/`. O painel HTML começa com GIFs pausados.
