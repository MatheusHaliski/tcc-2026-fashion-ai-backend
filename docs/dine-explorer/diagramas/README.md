# Dine Explorer — índice dos diagramas UML

Gerado por `scripts/dine-explorer/gerar.py` a partir de `scripts/dine-explorer/dados_rf.py` (RF1–RF29).
Arquitetura: **Spring Boot 4.0 · Java 25 (virtual threads)**, Spring Modulith, MySQL · Cassandra · Redis · OpenSearch · S3.

```bash
python3 scripts/dine-explorer/gerar.py --render /caminho/plantuml.jar
```
