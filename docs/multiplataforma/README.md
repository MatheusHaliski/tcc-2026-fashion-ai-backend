# FashionAI multiplataforma (Unreal Engine) — plano e estado

Migração do FashionAI de web app para aplicativo instalado em iPhone, iPad, Android, Windows, macOS, PlayStation e
Xbox, com Unreal Engine no núcleo 3D e o mesmo backend, a mesma conta, o mesmo avatar e o mesmo guarda-roupa.
