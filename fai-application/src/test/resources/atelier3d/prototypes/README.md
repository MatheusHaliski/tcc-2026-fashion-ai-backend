# Browser-generated GLB compatibility fixtures

Created by `scripts/atelier3d/audit-editor.cjs` using the local procedural templates in `lib/atelier3d/garment-template.ts` and the actual browser GLTFExporter. No brand asset, user photograph, external inference or production data.

`fai-*-prototype.glb` are generated imports. `export-*.glb` are confirmed exports; the tee includes a saved taper operation. The API in the browser scenario is an in-memory fixture. `GeneratedGarmentCompatibilityTest` separately checks all six binaries against the actual Java upload inspector.

These files prove format compatibility, not stitching, physical fit, certified sizing or realistic textile appearance. Regenerate through the browser audit when changing templates/export; review the screenshots before replacing fixtures.
