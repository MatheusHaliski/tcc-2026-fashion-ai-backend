# 07 — Modal de edição de dados (formulário longo/tabular)

Modal de tela cheia ou quase, com muitos campos — o metal precisa ficar restrito ao "esqueleto" para não cansar visualmente ao longo do formulário inteiro.

## Prompt — Claro

> Moldura externa com o gradiente-base completo. Cabeçalho fixo do modal (título + botão fechar) com o gradiente vertical mais sutil de sidebar/topbar. Barra de ações fixa no rodapé (salvar/cancelar) com o gradiente-base completo no botão primário. Cada seção/grupo de campos dentro do formulário usa **apenas** a borda metálica fina descrita em `02_forms.md` — nunca o gradiente de fundo cheio, senão o modal inteiro vira uma sequência de blocos brilhantes e a leitura cansa.

## Prompt — Escuro

> Mesma distribuição. O cabeçalho fixo e a barra de ações fixa são os dois pontos que devem continuar claramente "ancorados" visualmente mesmo com scroll longo no meio — as duas únicas faixas de metal sempre visíveis; o resto é grafite neutro.
